Copilot CLI をインストールして会話を試したので、次はプロジェクトに最初の変更を加えます。作業は小さく絞ります。ゲームのデータには星評価がすでにありますが、ホームページのゲームカードには表示されていません。エージェントに評価を表示するよう依頼し、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次の作業を行います。

- 機能ブランチで Copilot との会話を始めます。
- エージェントに小さな変更を依頼します。
- `/diff` で変更をレビューします。
- 転送されたブラウザーでアプリを実行し、変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価を設定でき、ゲーム詳細ページにはすでに表示されています。一方、ホームページのゲームカードにはタイトル、カテゴリ、発行元、説明だけが表示されています。最初の練習として、エージェントに各カードで既存の評価を表示させます。小さく独立した変更なので、最初のセッションに適しています。

## 会話の構成

**会話**は、Copilot CLI を使ってタスクに取り組む場所です。専用の worktree を作る Copilot app とは異なり、通常の CLI 会話では、ターミナルで現在チェックアウトしているリポジトリと Git ブランチを使用します。保存した会話に戻ることはできますが、ファイルとブランチはディスク上の通常の Git 状態として残ります。

会話では、プロンプトとエージェントの応答、ファイルを調査・編集するエージェントのツール操作、`/diff` で確認できる変更を扱います。

## 会話を始めて変更を依頼する

機能を実装するため、新しい会話を始めます。

1. Codespace に戻ります。
2. 以前のターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>`</kbd> (Windows/Linux) を押します。
3. まだ起動していない場合は、次のコマンドで Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. `/new` スラッシュコマンドを使って新しいセッションを開始し、<kbd>Enter</kbd> を押します。
5. 次のプロンプトを使って変更を依頼します。

   ```plaintext
   一覧ページのゲームカードに、各ゲームの starRating を 5 点満点で表示してください。評価が null の場合は "No rating yet" と表示してください。カードのレイアウトは変更せず、テストを追加して、関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調査し、ゲームの詳細を表示するファイルを見つけて、必要なコードを作成します。これで Copilot CLI を使った新機能の追加が完了しました。

## 差分をレビューする

小さな変更でも、AI が生成した変更はすべてマージ前にレビューします。Copilot CLI で変更を確認しましょう。

1. `/diff` を入力し、変更されたファイルをすべて確認します。
2. 評価が設定されている場合は数値が表示され、`starRating` が `null` の場合は `No rating yet` と表示されることを確認します。
3. 両方の状態がテストで確認されていることを確かめます。
4. Copilot が実行したチェックの結果をレビューし、失敗があれば修正を依頼します。
5. レビューが終わったら、<kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> すべての生成 AI ツールと同様、Copilot は確率的に動作するため、コードが完全に一致するとは限りません。特定の実装を期待するのではなく、動作をレビューしてください。

## 変更を確認する

コードを読むだけで動作すると判断せず、Copilot に Web サイトを起動して、Codespaces から転送されたブラウザーで確認できるよう依頼します。

1. 次のように依頼してアプリを起動します。

   ```plaintext
   アプリを起動して、ブラウザーで星評価の変更を確認できるようにしてください。URL を知らせて、サーバーは起動したままにしてください。
   ```

2. Codespaces がポート `4321` を利用できると通知したら、**Open in Browser** を選択します。
3. ゲームカードに 5 段階の評価が表示されていることを確認します。
4. Copilot に戻り、次のように依頼して起動したサーバーを停止します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初のプルリクエストを作成してマージする

機能を追加できました。新しいコードをプロジェクトにマージするため、プルリクエスト (PR) を作成します。

1. 既定のエージェントに次のように依頼し、変更をコミットします。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージを付けてコミットしてください。
   ```

2. `/pr create` を入力します。Copilot CLI は PR を作成する際に既存のコミットをプッシュし、PR の URL を表示します。
3. <kbd>Command</kbd> (Mac) または <kbd>Ctrl</kbd> (Windows/Linux) を押しながら、Copilot CLI に表示された URL を選択して PR を開きます。
4. 変更ファイルとチェック結果をレビューします。
5. 準備ができたら **Merge pull request** を選び、マージを確定します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```

- `/diff` で変更をレビューしました。
- 転送されたブラウザーでアプリを実行し、星評価を確認しました。
