Escolha um workshop de acordo com o que você quer aprender e o nível de aprofundamento desejado. **Primeiros passos** oferece uma introdução guiada ao GitHub Copilot, enquanto **Desenvolvimento no mundo real** usa uma aplicação completa e o backlog de uma equipe para praticar fluxos de trabalho voltados à produção.

## Primeiros passos

Comece com uma experiência guiada e focada que apresenta os principais recursos de um produto GitHub Copilot sem exigir uma base de código existente.

### [Tour do aplicativo GitHub Copilot][first-steps-app]

Crie um Space Quiz em uma pasta vazia, publique-o no GitHub, implemente uma issue, conclua uma revisão do Copilot, agende uma automação e explore um fluxo de trabalho com Canvas.

### [Primeiros passos com o GitHub Copilot CLI][first-steps-cli]

Crie o mesmo Space Quiz pelo terminal, revise diffs, execute sessões paralelas em worktrees, planeje antes de editar e crie, mescle e delegue pull requests sem sair do shell.

### [Primeiros passos com o Visual Studio Code][first-steps-vscode]

Crie o Space Quiz no VS Code, teste-o no navegador integrado, publique-o com Source Control, trabalhe com issues e pull requests usando as ferramentas do GitHub e transfira o trabalho para uma sessão na nuvem.

## Desenvolvimento no mundo real

Pratique o uso do GitHub Copilot em um ciclo de vida de desenvolvimento de software realista com a aplicação Tailspin Toys e o backlog da equipe. Escolha o ambiente de trabalho e, em seguida, planeje, desenvolva, teste, revise e entregue alterações relevantes.

### [Conheça os workshops de desenvolvimento no mundo real][real-world-development]

Escolha entre o GitHub Copilot CLI, o aplicativo GitHub Copilot, o agente de nuvem do GitHub Copilot ou o Visual Studio Code.

> [!CAUTION]
> O GitHub Copilot é probabilístico, não determinístico, portanto o código exato e os arquivos alterados podem variar em relação aos exemplos. Pequenas diferenças são esperadas.
>
> Se algo parecer quebrado ou não funcionar corretamente durante um workshop conduzido por um instrutor, peça ajuda a um mentor.
